## 👋 About Me

I'm a **final-year Computer Science student** focused on **AI engineering, workflow automation, backend development, and DevOps**.

I enjoy taking a problem that is repetitive, manual, or difficult to scale and turning it into a system that can do the work more reliably. My interests sit at the intersection of **AI, automation, APIs, data, and software engineering**.

I don't just want to build AI that can answer questions — I want to build systems where AI can **understand context, work with real data, connect to tools, and become part of an actual workflow**.

> **Understand the work → automate what repeats → add AI where judgment helps.**
